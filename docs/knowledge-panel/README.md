# Knowledge Panel de Hacia el Ocaso

Plan completo para que la banda tenga Knowledge Panel en Google y, más adelante,
presencia en Wikipedia.

**Empezá por [`CHECKLIST.md`](CHECKLIST.md)** — es el tablero con el estado de todo
y los datos que faltan.

| Documento | Contenido |
|---|---|
| [`CHECKLIST.md`](CHECKLIST.md) | Estado general, bloqueantes, orden de ejecución, registro de prensa |
| [`01-auditoria.md`](01-auditoria.md) | Qué existe hoy de la banda en internet, verificado fuente por fuente |
| [`02-wikidata.md`](02-wikidata.md) | Ítem completo con propiedades, valores, referencias y batch de QuickStatements |
| [`03-musicbrainz.md`](03-musicbrainz.md) | Artista y los 9 lanzamientos, con tracklists y duraciones |
| [`04-perfiles-verificados.md`](04-perfiles-verificados.md) | Spotify for Artists, Apple Music for Artists, OAC de YouTube |
| [`05-bio-oficial.md`](05-bio-oficial.md) | Bio corta, larga e inglés, consistentes para todas las plataformas |
| [`06-prensa.md`](06-prensa.md) | Medios, blogs y podcasts con contacto verificado + mails listos para enviar |
| [`07-knowledge-panel.md`](07-knowledge-panel.md) | Cómo aparece, cómo se reclama, cómo se verifica |
| [`08-wikipedia.md`](08-wikipedia.md) | Evaluación honesta de relevancia: hoy no alcanza, y qué falta |

## Regla de este plan

Ningún dato inventado. Cada ID, fecha y propiedad de estos documentos fue consultado
contra su fuente el 15/10/2026 (APIs de MusicBrainz, Apple Music, Deezer y Spotify,
endpoint SPARQL de Wikidata, y los sitios de cada medio). Lo que no se pudo
verificar está marcado con ⚠️.
